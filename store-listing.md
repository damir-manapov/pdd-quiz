# Описание для магазина приложений

Ограничения Google Play: короткое описание ≤ 80 символов, полное описание ≤ 4000
символов. Значения ниже — ориентир при редактировании, пересчитайте перед публикацией.

## Название

```
Экзамен ПДД — билеты
```

## Короткое описание (до 80 символов)

```
800 билетов ПДД офлайн: вопросы, пояснения, статистика и эффективный повтор.
```

## Полное описание (до 4000 символов)

```
«Экзамен ПДД» — современный офлайн-тренажёр для подготовки к экзамену в ГИБДД.
Изучайте правила дорожного движения без интернета, регистрации и рекламы.

ВОЗМОЖНОСТИ

- 800 вопросов из официальных билетов ПДД
- 37 тематических разделов: знаки, разметка, перекрёстки, скорость, приоритеты и
  многое другое
- 7 режимов прохождения: по порядку, случайно, слабые вопросы, давно не повторявшиеся,
  мало отвечаемые, с двумя ошибками подряд и с меньшим числом правильных подряд
- Перемешивание вариантов ответов в каждой сессии
- Подробные пояснения после каждого ответа, чтобы закреплять материал быстрее
- Детальная статистика по всем ответам и темам: общая точность, слабые вопросы,
  серии правильных и неправильных ответов
- Локальное хранение истории ответов на устройстве
- Экспорт и импорт истории в JSON-файл для резервного копирования и переноса
  прогресса между устройствами
- Полная офлайн работа: данные остаются только на вашем телефоне

ДЛЯ КОГО

Подойдёт кандидатам в водители, курсантам автошкол и всем, кто хочет повторять
правила дорожного движения в удобном темпе — дома, в дороге или в любой свободный
момент.

Материалы основаны на официальных экзаменационных билетах. Перед экзаменом
сверяйтесь с актуальной редакцией правил: законодательство периодически меняется.
```

## Примечания к публикации

- Категория: Образование
- Ключевые слова: ПДД, билеты ПДД, экзамен ГИБДД, правила дорожного движения, автошкола
- Иконка и заставка подготовлены для текущей версии приложения; перед публикацией
  проверьте их отображение на целевых устройствах.
- Скриншоты (не входят в репозиторий): экран сессии с вопросом, экран статистики,
  экран настроек.
