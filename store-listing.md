# Описание для магазина приложений

Ограничения Google Play: короткое описание ≤ 80 символов, полное описание ≤ 4000
символов. Значения ниже — ориентир при редактировании, пересчитайте перед публикацией.

## Название

```
Экзамен ПДД — билеты
```

## Короткое описание (до 80 символов)

```
Билеты ПДД офлайн: официальные вопросы, статистика и разбор ошибок.
```

## Полное описание (до 4000 символов)

```
«Экзамен ПДД» помогает подготовиться к экзамену в ГИБДД полностью офлайн — без
интернета, без регистрации и без рекламы.

ВОЗМОЖНОСТИ

- 800 вопросов из официальных билетов ПДД с изображениями и официальными
  вариантами ответов
- Вопросы сгруппированы по 37 темам (проезд перекрёстков, скорость движения,
  дорожные знаки, разметка и другие)
- Порядок вопросов на выбор: по порядку, случайно или «сложные сначала» —
  вопросы, в которых вы чаще ошибаетесь или которые давно не повторяли,
  показываются первыми
- Варианты ответов перемешиваются в каждой сессии
- Пояснение к каждому вопросу со ссылкой на пункт правил
- Статистика: общая точность, точность по темам и список слабых вопросов
- Резервная копия истории ответов в файл и восстановление из неё — ваш прогресс
  остаётся с вами
- Всё работает без сети: данные хранятся только на вашем устройстве

ДЛЯ КОГО

Для кандидатов в водители, курсантов автошкол и всех, кто хочет освежить знание
правил дорожного движения в удобном темпе, где угодно и без интернета.

Материалы основаны на официальных экзаменационных билетах. Перед экзаменом
сверяйтесь с актуальной редакцией правил: законодательство периодически меняется.
```

## Примечания к публикации

- Категория: Образование
- Ключевые слова: ПДД, билеты ПДД, экзамен ГИБДД, правила дорожного движения, автошкола
- Иконки и заставка в `assets/` — это временные плейсхолдеры, замените на финальную
  графику перед релизом.
- Скриншоты (не входят в репозиторий): экран сессии с вопросом, экран статистики,
  экран настроек.
